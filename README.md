# tp8
Projet avec le framework vue 3 JS.
L'application est un service de convertion de devise depuis la monais Franc Pacifique (XPF).
Pour set up et build le projet suivre les étapes suivantes.
Le projet contient un composant tableau qui gère la convertion et l'affichage des devises

Le projet a les dependance suivante :
- `vue` : framework JavaScript pour construire l'interface
- `vue-router` : gestion de la navigation
- `core-js` : polyfills pour la compatibilité des navigateurs

## Project setup
1. Ouvrez un terminal dans le dossier du projet :
   ```
   cd "dossier du projet"
   ```
2. Installez les dépendances :
   ```
   npm install
   ```

### Compiles and hot-reloads for development
```
npm run serve
```
Projet accessible via localhost:8080

### Compiles and minifies for production
```
npm run build
```
